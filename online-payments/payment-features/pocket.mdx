---
title: Pocket
---

The pocket functionality allows merchants to send out funds from their seerbit pockets, to other pockets, sub-pockets, or other banks (payout).

> Please note that merchants must be approved if they are to use the payout feature (For API cases only).

Once an account is approved on the seerbit merchant dashboard here, customer has a pocket Id attached to them. Merchant should then attempt logging in here on the pocket dashboard or reset password if the password reset email sent to merchant was missed.

## Authentication

This authenticates that user is valid for the pocket APIs. With the encrypted key, you can then have access to other endpoints.

<Badge color="blue">POST</Badge>

```bash
https://pocket.seerbitapi.com/pocket/authenticate
```

#### Request Sample

```bash cURL
curl --location 'https://pocket.seerbitapi.com/pocket/authenticate' \
--header 'Content-Type: application/json' \
--data-raw '{
    "email": "youremail.com",
    "password": "password"
}'
```

#### Response Sample

The code snippet below shows a sample response

```json
{
  "responseCode": "00",
  "message": "Success",
  "data": {
    "bearerToken": "",
    "expiryTime": "2025-04-22T20:09:09",
    "requirePasswordChange": true
  }
}
```

## Changing Password

Change your password only if it's required after your authentication

<Badge color="blue">POST</Badge>

```bash
https://pocket.seerbitapi.com/pocket/user/change-password
```

```bash cURL
curl --location 'https://pocket.seerbitapi.com/pocket/user/change-password' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {{YourEncryptedKey}}' \
--data-raw '{
  		"currentPassowrd": "johndoe@email.com",
 	 	"newPassword": "password"
}'
```

## Adding A Sub-Pocket

<Badge color="blue">POST</Badge>

```bash
https://pocket.seerbitapi.com/pocket/pocket-id/{{PocketID}}/sub-pocket
```

> The **'AddASubPocket'** API adds a sub pocket that's delegated to a merchant's third-party user.

## Pocket to Pocket Transfer

This allows you to make intra transfers between pockets.

<Badge color="blue">POST</Badge>

```bash
https://pocket.seerbitapi.com/pocket/transfer/from-pocket/{{PocketID}}/to-pocket/{{PocketID}}
```

#### Request Sample

```bash cURL
curl --location 'https://pocket.seerbitapi.com/pocket/transfer/from-pocket/{{PocketID}}/to-pocket/{{PocketID}}' \
--header 'Content-Type: application/json' \
--header 'Public-Key: your_public_key_here' \
--header 'Authorization: Bearer YOUR_ENCRYPTED_KEY' \
--data-raw '{
  "amount": 100,
  "currency": "NGN",
  "reference": "{{reference}}",
  "description":"Test description"
}
```

#### Response Sample

The code snippet below shows a sample response

```json
{
  "responseCode": "00",
  "message": "Successful",
  "data": {}
}
```
