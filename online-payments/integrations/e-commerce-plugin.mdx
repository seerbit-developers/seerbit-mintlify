<h3 noAnchor>Launch faster with zero code</h3>

SeerBit’s official plugins enable secure, PCI-compliant payments across leading e-commerce
platforms and business software. Get started in minutes, not days, with seamless integration and
reliable performance.

> **All plugins listed here have the same level of security as our other integration methods.**

## Before You Start

- **Retrieve API Keys**: Log in to your [SeerBit Dashboard](https://dashboard.seerbit.com/#/auth/login) and navigate to **Settings > API Keys** to copy your **API Keys**.
- **Start in Test Mode**: Configure the plugin using **Test Keys** first. Complete at least one successful test transaction before switching to Live mode.

## Usage

Use any of our recommended solutions for your platform.

## Next Steps After Installation

- **Test all payment methods** using [SeerBit test cards](/testing/overview).
- **Verify transactions** using your [payment verification process](/online-payments/after-payments/verify-payment).

## Notes

> Ensure you have your public key. You can find this on the SeerBit Merchant dashboard under accounts > api keys. If you don’t have an account with us yet, you can [create a test account now](https://dashboard.seerbit.com/#/auth/register)
