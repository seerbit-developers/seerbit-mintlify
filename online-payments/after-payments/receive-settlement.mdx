All businesses on SeerBit are paid automatically — as a SeerBit merchant you do not have to request settlement. After deducting our charges, we pay the entire sum of transactions received in a day into your bank account. However, settlements availability depends on some factors such as the business country and industry your business is operating in.

> **When does a merchant receive their settlement?**

Naira transactions are on a settlements schedule of T+1 - this means that we automatically pay the total sum received to the merchant on the next working day after the transaction day.

> **International settlement in Nigeria?**

To get your settlements for USD transactions you will need a [United Bank for Africa Domiciliary account](https://www.ubagroup.com/nigeria/personal-banking/accounts/domiciliary-account/).

## Global Settlement Schedule

| Country     | Local Payments                | International Payments                          |
| ----------- | ----------------------------- | ----------------------------------------------- |
| Nigeria     | Next Working Day ( T + 1 )   | 5 days from when transaction was done ( T + 5 ) |
| Kenya       | Next Working Day ( T + 1 )   | 5 days from when transaction was done ( T + 5 ) |
| Senegal     | Next Working Day ( T + 1 )   | 5 days from when transaction was done ( T + 5 ) |
| Tanzania    | Next Working Day ( T + 1 )   | 5 days from when transaction was done ( T + 5 ) |
| Ghana       | Two Working Days ( T + 2 )   | 5 days from when transaction was done ( T + 5 ) |
| Ivory Coast | Two Working Days ( T + 2 )   | 5 days from when transaction was done ( T + 5 ) |
| Cameroon    | Two Working Days ( T + 2 )   | 5 days from when transaction was done ( T + 5 ) |
| Uganda      | Two Working Days ( T + 2 )   | 5 days from when transaction was done ( T + 5 ) |
