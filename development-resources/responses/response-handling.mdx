---
title: Response Handling
---

> In case of an error, the response object contains the follow fields:

| Field   | Type     | Required? |
| ------- | -------- | --------- |
| message | `string` | Yes       |
| error   | `string` | Yes       |

```json
{
  "message": "Confirm Merchant Environment",
  "error": "PROCESSING"
}
```
