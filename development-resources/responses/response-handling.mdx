---
title: Response Handling
description: The shape of an error response and how to read it.
---

When a request fails, the response object contains the following fields:

| Field   | Type     | Required? |
| ------- | -------- | --------- |
| message | `string` | Yes       |
| error   | `string` | Yes       |

```json
{
  "message": "Confirm Merchant Environment",
  "error": "PROCESSING"
}
```

The `error` value is a short machine-readable label and `message` explains the failure. For transaction outcomes — as opposed to request errors — read `data.code` instead, and see [SeerBit status codes](/development-resources/responses/seerbit-status-code).
