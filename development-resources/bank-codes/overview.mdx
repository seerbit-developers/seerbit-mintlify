title: Bank Codes
description: NIP institution codes to use as the bankCode when sending a payout to a Nigerian bank account.
---

Use these codes as the `bankCode` when you [send a payout](/online-payments/payment-features/payout) to a Nigerian bank account. Each code is the six-digit NIP institution code that identifies the receiving bank on the NIBSS Instant Payment network.

> **Fetch the live list in production.** Banks merge, change names and lose licences, so this page is a reference snapshot. Call the [bank list endpoint](/online-payments/payment-features/payout#bank-list) for the current list, and use this page to look up a code while you build.

> **These are not the three-digit CBN sort codes** (such as `058`). NIP codes are six digits — GTBank is `000013`. Sending a three-digit code as the payout `bankCode` will not resolve to the right bank.
